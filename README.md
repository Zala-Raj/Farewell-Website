# Farewell Website – Gift From Batch 2024-25

A small digital gift for our beloved teachers from the Science Batch 2024-25.

This website was created to express our gratitude, respect, and appreciation for the teachers who guided us throughout our academic journey. It is a simple farewell surprise filled with heartfelt messages and memories.

**Live Website:** https://science-old.netlify.app

## Features

- Special farewell messages for teachers.
- Interactive text elements with surprise messages.
- Simple and user-friendly design.
- A digital way to express gratitude and appreciation.

## Built With

- HTML
- CSS
- JavaScript

## Preview

Visit the live website to explore the farewell experience.

## Purpose

This project was made as a farewell gift from the Science Batch 2024-25 to our teachers.

Sometimes, a few words are enough to express what we feel. This website is one small attempt to say **Thank You!**
